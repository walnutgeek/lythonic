# v0.0.22

## New: FrameData tabular data model

`lythonic.frame.FrameData` is a Pydantic model for tabular data stored as
`columns` + row-oriented `data`. It serializes to/from JSON with no
DataFrame library dependency.

Conversion methods for pandas, polars, and pyarrow lazily import their
respective libraries, so they are only needed when actually used. New
optional extras `pandas`, `polars`, and `pyarrow` install them; CI runs a
matrix job testing each extra individually.
